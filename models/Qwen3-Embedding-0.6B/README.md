# Qwen3-Embedding-0.6B

Suzhan uses Qwen/Qwen3-Embedding-0.6B with 1024-dimensional embeddings.

The model.safetensors file is stored as a Git LFS pointer. Its upstream revision and SHA-256 are recorded in tcm-model-lock.json. Download the large object only after confirming the upstream model license and your Git LFS quota.
